## [0.1.0] - 2026-08-14

### Added

- AI test generation from stories and recordings
- Groq-to-Gemini routing for large requests
- Test Library with execution states and automation previews
- Playwright, Cypress, and Selenium starter generation
- GitHub OAuth, repository creation, issue publishing, and QA asset publishing
- Project profiles, telemetry analysis, bug tracking, and responsive interface
- Futuristic TestMind visual identity and documentation

### Security

- API and AI endpoint rate limits
- Standard HTTP security headers
- Video file signature validation
- Optional AES-256-GCM encryption for stored GitHub tokens
